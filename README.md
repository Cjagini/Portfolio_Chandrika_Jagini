# Chandrika Jagini - Professional Portfolio

A modern, responsive React portfolio website showcasing professional experience, skills, projects, and achievements.

## Features

- **Hero Section**: Eye-catching landing section with call-to-action buttons
- **About**: Professional summary and quick facts
- **Skills**: Organized skill categories with badges
- **Experience**: Detailed work history with key accomplishments
- **Projects**: Featured AI and full-stack projects with descriptions
- **Education**: Academic credentials, certifications, and awards
- **Contact**: Contact information and message form
- **Responsive Design**: Mobile-friendly layout with smooth navigation
- **Modern UI**: Tailwind CSS with gradient effects and hover animations

## Technology Stack

- **Frontend**: React 18.2, Vite
- **Styling**: Tailwind CSS 3.4
- **Icons**: React Icons 5.0
- **Build Tool**: Vite 5.0
- **PostCSS**: For Tailwind processing

## Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd c:\Users\chand\PortfolioCJ
```

2. Install dependencies:
```bash
npm install
```

### Development

Start the development server:
```bash
npm run dev
```

The portfolio will be available at `http://localhost:5173`

### Build

Build for production:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## Customization

### Colors
Edit `tailwind.config.js` to change the color scheme. Current theme uses:
- Primary: Dark slate (`#1f2937`)
- Secondary: Blue (`#3b82f6`)
- Accent: Green (`#10b981`)

### Content
Update component files in `src/components/` to modify portfolio content.

### Fonts
Customize fonts in `index.css` or `tailwind.config.js`
